# 售后运营数据报表

这是一个基于HTML的售后运营数据报表工具，支持查看当前周和历史周数据。

## 访问地址

https://yywu-rich.github.io/data-report

## 数据更新

数据存储在 `index.html` 文件的 `reportData` 变量中，通过更新该变量即可更新报表数据。

## 功能特点

- 📊 多维度数据展示：P1工单、安全问题、企微来源工单、P4工单、电话数据、一线/二线工单及解决率
- 📅 按周期查看：支持查看不同周的数据
- 🔄 同期对比：26年与25年同期数据对比
- 🏷️ 假期标记：自动识别春节、国庆、五一等假期并特殊显示
