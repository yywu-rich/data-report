# 数据抓取工具使用说明

## 访问地址
- 报表页面：https://yywu-rich.github.io/data-report/
- 抓取工具：https://yywu-rich.github.io/tools.html

---

## 快速使用

### 1. 添加书签脚本

1. 访问工具页面：https://yywu-rich.github.io/tools.html
2. 显示浏览器书签栏：`Ctrl+Shift+B`（Windows）或 `Cmd+Shift+B`（Mac）
3. 用鼠标拖拽书签按钮到书签栏

### 2. 抓取数据

在对应后台页面点击书签即可：
- 企微后台 → 点击"抓取企微数据"
- 七鱼后台 → 点击"抓取电话数据"
- 解决率页面 → 点击"抓取解决率"

### 3. 发送数据

数据会自动复制到剪贴板，直接发给我即可更新报表。

---

## 备用方案：手动抓取

如果书签脚本无法使用，可以手动复制数据发给我：

### 企微数据格式
```
周期：XX年(X.X-X.X)
会话量：XXX
派单工：XXX
P4工：XXX
```

### 电话数据格式
```
周期：XX年(X.X-X.X)
接入量：XXX
接通率：XX.X%
```

### 二线解决率格式
```
周期 | 周解决率 | 工单量
X.X~X.X | XX.XX% | XXX
```
